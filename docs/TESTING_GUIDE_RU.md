# Как проверить Adventy

## Обычная страница
- На компьютере откройте главную страницу. Фасад должен помещаться в экран без вертикальной прокрутки, в том числе в широком и невысоком окне браузера.
- На телефоне прокрутите страницу до окна №31 и входа. Горизонтальной прокрутки быть не должно.
- Откройте карточку и закройте её крестиком или клавишей Escape. На телефоне страница должна остаться там же.
- На хостинге окна открываются в 00:00 по Москве. Тестовой панели там нет.

## Проверка дат на своём компьютере
1. Запустите API и клиент по [инструкции локального запуска](LOCAL_DEVELOPMENT.md).
2. Откройте http://127.0.0.1:5173/?preview=1 и выберите «Тестовая дата» под домом.
3. На 30 ноября нажмите на окно №1: стекло тонировано, задания ещё нет. Звезда над входом показывает подсказку к 1 декабря.
4. На 6 декабря нажмите на №6: есть задание и ссылка «тут». У №7 тонировано стекло и есть заглушка, у №8 закрыты ставни.
5. На 31 декабря нажмите на гирлянду вдоль крыши: откроется поздравление.

Этот режим работает только при локальном запуске в Development. ZIP для HR — отдельная локальная сборка, его не загружают на хостинг.

При публикации замените сервер и клиент вместе. Используйте чистый каталог для новой версии или уберите старые файлы клиента из публичного `wwwroot`, включая файлы с прежними хешами в именах. Простое копирование поверх старой сборки оставит её файлы доступными. Если они когда-либо публиковались, проверьте также кеш CDN.

Каталог `DecorationAssets` должен лежать рядом с `Api.dll`, вне публичного `wwwroot`. Держите его вне публичной папки и на хостинге. Список и картинки украшений отдаёт API после проверки даты по Москве. Список не кешируется, а открывшиеся картинки можно кешировать по версии в их адресе.
