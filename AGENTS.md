# Adventy

Adventy — декабрьский календарь для коллег техотдела. С 1 по 31 декабря 2026 года открываются задания. Результат участники отправляют в чат отдела в Telegram. Интерфейс на русском, без учётных записей. Стек — React 18, Vite 5, ASP.NET Core на .NET 9.

## Как работать с Иваном

- Общайся по-русски и по делу. Сначала говори, что уже работает и что Иван может открыть или проверить. Для ручной проверки давай конкретные шаги, адрес, дату и номер окна.
- Работаем по порядку, в текущей папке `C:\Users\ivan.gerasimov\Calendar\adventy`. Начинай с `git status --short --branch`. Сохраняй текущие изменения, включая незакоммиченные часы API и тесты. Без отдельной команды не создавай worktree, не коммить, не пушь и не выкладывай на домен. Публикация — отдельный этап.
- Если связь оборвалась или Иван просит перепроверить, сначала выясни, что сохранилось и что уже запущено. Доделай начатое и укажи, что проверил в браузере, что проверил тестами и где остались ограничения.
- Графику оценивай на странице целиком и в реальном размере окна. Крупные изображения могут быть исходными слоями. Для согласования важен вид фасада и карточки в браузере. Если браузер блокирует доступ, используй свежие снимки от Ивана и обозначь границы проверки. Запрет доступа не обходи.
- Заголовки заданий — короткие, разные, живые и по смыслу конкретного задания. Ориентир для 3 декабря — «Жёлтый переполох» для поиска и фото жёлтого объекта. Избегай повторов, общих ярлыков вроде «Новогоднее задание» и случайных метафор. Тексты, привязку заданий к дням и ссылку «тут» 6 декабря сохраняй.

## Что сейчас есть

- На `/` — рисованный зимний дом. На десктопе 31 интерактивное окно, два остеклённых холла и два декоративных закрытых окна после №9 и №19. У №6 такая же архитектура, как у остальных чердачных окон. «Как участвовать» находится справа вверху на месте надписи «Декабрь 2026». Слоган и нижняя инструкция убраны.
- В каждом из 31 окна своя жилая комната из общего атласа. Переплёты текстурные, деревянные. Номер на закрытом окне разделён между створками и движется вместе с ними. Прошедшие дни и сегодня видны через прозрачное стекло, завтра — через стекло с фиксированной тонировкой, остальные закрыты ставнями. 30 ноября окно 1 уже тонировано. Смена состояния привязана к полуночи по Москве. Клик по будущему окну показывает заглушку без текста задания.
- `/api/clock` отдаёт серверное время UTC, клиент определяет календарный день по Москве. В Development селектор «Тестовая дата» на `/?preview=1` и `/window-preview` позволяют проверить 29 ноября 2026 — 1 января 2027. Дата меняет и вид окон, и доступ к заданиям. DEV-эндпоинт `/api/dev/window-preview/adventure` повторно проверяет доступ. Основной API не принимает тестовые параметры для обхода даты.
- Карточка выглядит как зимнее письмо с рисованными фонарём, еловой веткой, конвертом и ключом. Декоративные эмодзи убраны из заголовков карточек. Диалог закрывается крестиком, Escape или по фону, удерживает прокрутку и возвращает её после закрытия. После клика мышью обводка на окне не остаётся, для клавиатуры видимый фокус сохранён. На компьютере сцена подстраивается под высоту экрана; мобильную страницу можно прокручивать.
- На экранах до 700 px включительно используется отдельная иллюстрация мобильного дома с крышей, кирпичным фасадом и входом. Окна идут по три в ряд, №31 по центру. Мобильная страница прокручивается вертикально. Код и сборка проверены, новая композиция ещё ждёт визуальной проверки на узком экране.

- `PRODUCT.md`, `DESIGN.md`, `.impeccable/mocks/decision/` — ограничения продукта, визуальные решения и макеты. Для жилых комнат ориентир — `.impeccable/references/feedback-2026-11-05/desired-rooms.png`. - `src/Api/ClientApp/src/App.jsx`, `App.css` и `lib/houseLayout.js` — фасад и расположение окон. `components/AdventWindow.jsx` и `.css` — слои и анимация, `components/CalendarDialog.jsx` — карточка и её поведение. `assets/house/`, `assets/window-demo/` и `assets/task-card/` — иллюстрации.
- `src/Api/Controllers/` — часы и доступ к заданиям. `src/Domain/DailyAdventureProvider.cs` — заголовки и тексты заданий. `docs/LOCAL_DEVELOPMENT.md` — запуск.

## Локальный запуск и проверка

1. В `src/Api` запусти `dotnet run` (порт 5131). В другом терминале, в `src/Api/ClientApp`, запусти `npm.cmd run dev` (порт 5173). При первом запуске установи зависимости через `npm.cmd install` в папке клиента.
2. Открой `http://127.0.0.1:5173/`. Если порт занят, сначала проверь, отвечает ли уже запущенный сервер Adventy. Vite может автоматически перейти на 5174 при запуске второго экземпляра.
3. Для клиента запускай `npm.cmd test` и `npm.cmd run build` из `src/Api/ClientApp`. Для API запускай `dotnet test Adventy.sln` из корня. В последней проверке клиента прошли 16 тестов и production-сборка. История проверок API — в локальных заметках.

Сегодняшняя деталь открывает подсказку к завтрашнему заданию, а гирлянда 31 декабря — поздравление. Для проверки выбери в «Тестовой дате» 30 ноября и нажми на тонированное окно №1, затем на звезду над входом. 31 декабря нажми на огни вдоль крыши. Исходные координаты и названия украшений хранятся в скриптах `src/Api/ClientApp/scripts/`. Скрипт `build-decoration-manifest.mjs` собирает закрытый каталог `src/Api/DecorationAssets` рядом с серверными картинками. Браузер получает только уже открывшиеся украшения и картинки через API. Стихи лежат в `src/Domain/DecemberHints.cs`; API отдаёт только текст украшения, доступного сегодня по Москве. Тестовый запрос за подсказкой разрешён только в Development.
