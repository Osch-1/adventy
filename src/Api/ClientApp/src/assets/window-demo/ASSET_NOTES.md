## Wooden sash prompt

One transparent PNG game/UI asset: thin wooden window sash seen EXACTLY straight on, orthographic front elevation, tall rectangular outer perimeter with a central vertical wooden mullion and one horizontal wooden transom 37 percent down from top, creating four completely TRANSPARENT empty pane holes.
