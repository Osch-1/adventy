## Графика для сайта

PNG в `house/`, `window-demo/` и `task-card/` — рабочие исходники. Сайт использует общую графику из `src/assets/optimized/`. Готовые украшения и их каталог лежат в серверной папке `src/Api/DecorationAssets`, вне `wwwroot`. При смене названий или координат без перерисовки можно выполнить `node scripts/build-decoration-manifest.mjs` из папки клиента. Чтобы пересобрать их после правки PNG или областей в `scripts/decorationArt.js`, запусти из `src/Api/ClientApp`:

```powershell
node scripts/optimize-art.mjs "C:/path/to/cwebp.exe"
```

Подходит [cwebp из комплекта WebP](https://developers.google.com/speed/webp/docs/precompiled). Если он есть в PATH, аргумент можно опустить. Фасады сохраняют исходные размеры. Кадры украшений вырезаются без потерь и небольшим запасом по краям, чтобы сохранить привязку к фасаду. Атлас комнат разделён по рядам; браузер запрашивает полосу, только когда открывается хотя бы одно её окно. Сборка Vite использует готовые WebP и не требует конвертера.

Сравнение по размерам файлов сборки без кэша и без открытой карточки: 30 ноября на десктопе 12,90 → 1,09 МБ, на мобильном 10,93 → 1,15 МБ; 31 декабря на десктопе 33,17 → 2,73 МБ. Это объём графики, не замер времени ответа хостинга.
